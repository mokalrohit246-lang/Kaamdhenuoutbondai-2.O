Quick Start Guide

  1. Configure API Keys: Go to Settings and add your LiveKit, Gemini, and Vobiz SIP credentials.
  2. Setup SIP Trunk: Use the ⚡ Create SIP Trunk button to auto-provision your number.
  3. Define Agent Profile: Create an agent with your preferred voice and AI model.
  4. Customize Prompt: Write your sales script in the AI Prompt tab.
  5. Test Single Call: Go to the Single Call tab and call your own number.
  6. Launch Batch: Upload a CSV to begin an automated outbound campaign.
